# Order Icons

This folder should contain SVG icons for taxonomic Orders.
These icons appear in the centre of Family Ribbons.

## Specifications

| Property | Value |
|----------|-------|
| Format | SVG |
| Size | 100×100 viewport |
| Style | Black silhouette, minimal detail |
| Naming | Lowercase, Latin name (e.g., `coleoptera.svg`) |

## Adding Icons

1. Download from PhyloPic (https://www.phylopic.org)
2. Or generate with AI using this prompt:
   ```
   Simple black silhouette icon of a [ORGANISM], side view, 
   minimal detail, solid fill, no background, clean edges, 
   suitable for small display at 48px, biological illustration style
   ```
3. Save as lowercase Latin name (e.g., `lepidoptera.svg`)

## Fallback

If an icon is missing, the renderer will display a plain circle.
